## Acceptance

- 24 fixed English/Swedish cases across choice/score/noul and ordinary/negated/ambiguous/long inputs: ten identical repetitions per case in each environment; unchanged answers/ranks and maximum numeric delta **0.0** (limit 0.000001).
- 50 warmed requests at each concurrency in each environment: no errors and every request below 30 seconds; both candidate p95 ratios below 1.2.
- Four synchronized clients: **200, 200, 503, 503**, followed by working inference.
- Root-owned immutable model bundle; actual unprivileged write denial, known old/new cache migration, normalization no-op, network-blocked startup and a fresh process restart. Restart reproduced all 24 candidate response bodies.
- 59 contract/security/stack tests; clean pinned installation and pip consistency; CPU-only package checks; compilation, shellcheck, Terraform formatting/init/validation and stack packaging passed.
- Final 65-package OSV audit had zero matches; public Dependabot reported zero open findings when checked. This is a bounded published-advisory check, not proof of vulnerability absence.

## Artifact verification

All eleven published assets were downloaded. Every entry in SHA256SUMS matched; the release manifest commit matched the immutable tag, and the model manifest digest matched release identity. The actual released runtime ZIP passed the private offline staging verifier. The runtime contains nine allowlisted files (13,246 bytes compressed); the stack contains nineteen (21,965 bytes). Neither contains model weights, caches, credentials or private operational data. The generated cloud-init payload was also checked: 15,208 bytes of YAML / 20,280 base64 bytes with a synthetic secret reference.

## Scope and handover

The private adoption package was separately prepared with reviewed digests, archive rejection tests, service-user load preflight, controlled runtime/model switch and fail-closed rollback. No existing deployment was contacted or changed. Live preflight, authentication, performance, process/reboot recovery and 30 consecutive one-minute health checks remain operator gates.

Protection assumes a trusted release and root administrator. Model copies and hashing add storage/startup cost; neither protects against compromised root or a malicious approved source release. The registered-decisions plan and prohibition on customer data remain unchanged.
